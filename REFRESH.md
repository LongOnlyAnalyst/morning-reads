# Daily refresh procedure

0. **Use feedback (before sourcing).** First run `python3 ingest_feedback.py --sync`: the page auto-syncs Zane's ratings and read state into one GitHub issue (number in local, git-ignored `sync.json`, with the limited token); this pulls it into `feedback.json`. Never commit `sync.json`. Then handle manual issues: Run `gh issue list -R LongOnlyAnalyst/morning-reads --state open --json number,title,body,createdAt`. Zane's "Send to Reading List" button opens issues titled "Ratings export <date>" with a JSON code fence. Ingest them with `python3 ingest_feedback.py --issues --close`, which parses each body, merges into `feedback.json` keyed by URL (latest `ratedAt` wins), and closes each issue with the comment "ingested". If Zane pastes an export JSON in chat, save it to a file and run `python3 ingest_feedback.py <file>`. The script prints good/neutral/bad counts per source and per tag. **Ranking:** once there are at least ~5 ratings, favor sources and tags that are mostly "good", and drop any source or tag with 2 or more "bad" and no "good". Below ~5 ratings, leave the source list unchanged. Commit `feedback.json` with the refresh.
1. **Find candidates (search wide every run).** Zane said on November 11, 2026 that the sources felt narrow and he kept seeing the same publishers. Every refresh, search the whole list below for pieces from the last ~7 days first (prefer the last 1 to 3 days), then reach back toward ~30 days only for the backlog. Never log in anywhere. Reject newswire filler, listicles, stock-pick promos, aggregator roundups, corporate promo blogs, and stale pieces.
   - Core shops (still eligible, but do not let them fill the page): Citadel Securities (GMI, Macro Thoughts, Global Macro Strategy), BIS (Bulletins, Working Papers), Fed FEDS Notes (federalreserve.gov/econres/notes/feds-notes/2026-index.htm), NY Fed Liberty Street, BNY iFlow, Matt Levine, Odd Lots, Net Interest, a16z, Stratechery free posts, Goldman/JPM/BlackRock institute research, ECB blog.
   - Other Fed banks: Dallas Fed Economics, Chicago Fed Letter, Kansas City Fed Economic Bulletin, SF Fed Economic Letter, Richmond Economic Brief, Cleveland Economic Commentary, Atlanta Policy Hub, Boston, St. Louis, Minneapolis, Philadelphia.
   - Other official sector: BoE Bank Underground, Banque de France Eco Notepad, Bundesbank, Bank of Canada, OFR blog, FSB, IMF blog/GFSR, ESRB.
   - Think tanks and research: PIIE RealTime Economics, Brookings Hutchins, VoxEU/CEPR, Bruegel, NBER Digest, Rhodium Group, Columbia CGEP, Oxford Institute for Energy Studies.
   - AI, compute and industry: Epoch AI, SemiAnalysis (paywall; only if the free part is substantive), The Diff (label paywall if needed), Construction Physics.
   - Buy side and markets: Oaktree/Howard Marks, Bridgewater, AQR, Man Group, Two Sigma, GMO, Research Affiliates, KKR (McVey), serious private-credit research, Citi GPS/Morgan Stanley/UBS only if data-heavy, Fedguy if a post is substantive, Breakingviews or FT Alphaville only if substantive (paywall), Apollo/Slok only if data-heavy.
   - Wider sources used before when thin: BNY iFlow, Apricitas.
2. **Verify each one.** Fetch it and confirm HTTP 200 (a 403 bot-block is OK if the page is clearly real, e.g. Citadel). Read the publication date from the page itself and never guess it. Read time = word count / 230. Write a 2-sentence "why it matters" based on what you actually read. Set `paywall: true` for gated content. Give every item `tags`: 1 to 3 short topic labels such as "market structure", "AI credit", "macro", "rates", or "positioning".
3. **Dedupe.** Skip any URL already in `history.json` (any status), unless it is still current and is being kept in `items.json`.
4. **Prune.** Remove items from `items.json` whose `date` is more than ~30 days before today. `build.py` keeps them in history and marks them `expired`.
5. **Pick today's top 3.** Set `"top": true` on exactly 3 items (the freshest, highest-insight pieces, from the last ~7 days, newest first) and remove `top` from the others. **Publisher diversity:** the 3 top items must come from 3 different publishers, and should not repeat a publisher that was in the previous refresh's top 3 when another high-quality source has fresh work. Do not rotate the same few shops (Citadel, BIS, FEDS Notes, Liberty Street, BNY iFlow, Levine, Odd Lots) into the top slot by default. Across the page, keep any one publisher to about 3 items, and make most new adds each run come from publishers not already on the page unless a piece is clearly exceptional. Aim for 12–20 backlog items. Never pad the list.
6. **Rebuild.** Run `python3 build.py $(date +%F)`. This regenerates `index.html` and updates `history.json`. listedOn is set only when an item first appears.
7. **Check.** Run a headless check: `google-chrome --headless=new --no-sandbox --window-size=1200,1600 --screenshot=/workspace/morning-reads-preview.png file:///home/box/morning-reads/index.html`, and confirm there are 3 top items.
8. **Ship.** Run `git add -A && git commit -m "refresh $(date +%F)" && git push origin main`.
9. **Verify live.** After GitHub Pages deploys (https://longonlyanalyst.github.io/morning-reads/, takes ~1 min after push), `curl -s <live-url> | grep -c 'Updated '` and confirm today's date appears in the Updated line (`grep "Updated $(date '+%B %-d, %Y')"`).
